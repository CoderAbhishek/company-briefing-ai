# Pre-Call Intel Briefing Tool
An AI-powered interview prep tool that researches any company 
in real-time before your HR call.

Built with: HTML + Anthropic Claude API (web search enabled)

## How to use
1. Open index.html in any browser
2. Paste your Anthropic API key (get one free at console.anthropic.com)
3. Type company name + role → get instant briefing

## What it does
- Latest company news & funding rounds
- Talking points tailored to your background  
- Smart questions to ask HR
